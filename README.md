# AR/VR-Powered Disaster Preparedness & Response Education System

An immersive AR/VR-based educational platform designed to improve disaster preparedness and emergency response awareness through interactive simulations, gamified learning experiences, and real-time training scenarios.

## Overview

This project aims to provide an engaging learning environment where users can experience realistic disaster situations in a safe virtual environment. The platform helps learners understand disaster management procedures, emergency response techniques, and safety protocols through interactive simulations.

## Key Features

### Immersive Disaster Simulations

* Earthquake preparedness training

## Installation

### Clone Repository

```bash
git clone https://github.com/Nitish2507-cloud/VR_Training_Simulation.git
```

### Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

### Backend Setup

```bash
cd backend
npm install
npm start
```
